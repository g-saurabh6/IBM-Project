# Cybersecurity Policy

## 1. Introduction

This cybersecurity policy defines the basic security rules and practices for our small business. Its purpose is to protect company data, systems, devices, and employees from cyber threats.

## 2. Password Policy

- Employees must use strong and unique passwords.
- Passwords should contain uppercase letters, lowercase letters, numbers, and special characters.
- Passwords must not be shared with other employees.
- Multi-factor authentication (MFA) should be enabled wherever possible.
- Default passwords must be changed immediately.

## 3. Access Control

- Employees should only have access to the data required for their job.
- User accounts must be created and removed by an authorized administrator.
- Employees must lock their computers when leaving their workplace.
- Administrative privileges should only be given when necessary.

## 4. Email and Phishing Security

Employees must be careful when opening emails, attachments, and links.

Suspicious emails should be reported to the system administrator.

Employees must not provide passwords, OTPs, or sensitive information through unknown emails or messages.

## 5. Device Security

- Company computers must have updated operating systems and security software.
- Antivirus and firewall protection should remain enabled.
- Unauthorized software must not be installed.
- Lost or stolen devices must be reported immediately.

## 6. Data Protection

Important business information must be stored securely.

Sensitive information should only be accessible to authorized employees.

Regular backups must be maintained to protect against accidental deletion, hardware failure, ransomware, or other incidents.

## 7. Backup Policy

- Important data should be backed up regularly.
- At least one backup should be stored separately from the main system.
- Backups should be tested periodically.
- Backup access must be restricted to authorized personnel.

## 8. Employee Security Awareness

Employees should receive basic cybersecurity training covering:

- Phishing attacks
- Password security
- Social engineering
- Safe internet usage
- Malware awareness
- Reporting security incidents

## 9. Incident Reporting

Any suspected cybersecurity incident must be reported immediately to the responsible administrator.

Examples include:

- Suspicious emails
- Malware detection
- Unauthorized login
- Data leakage
- Lost or stolen devices
- Ransomware attacks

## 10. Policy Review

This cybersecurity policy should be reviewed periodically and updated when there are significant changes in the organization's systems, threats, or business requirements.
